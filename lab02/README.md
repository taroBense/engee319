### 🔑 Gemini API Key Setup

This app requires a Google Gemini API Key to translate natural language into lamp colors.

1. Get a **free API key** from [Google AI Studio](https://aistudio.google.com/).
2. On your first launch, the app will prompt you to enter your API key, unless you store it in `$GEMINI_API_KEY`.
3. The key is saved locally on your machine and is never shared.
